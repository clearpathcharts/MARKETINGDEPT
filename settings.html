Settings

Console-level settings. Changing these means editing the files directly — nothing here saves from the browser yet.

Login password

To change your password:

  1. Open auth.js in a text editor
  2. Find the line that starts with APP_PASSWORD
  3. Replace the text between the quotes
  4. Save the file

Session length

How long you stay logged in before it asks for the password again. Currently set to 12 hours in auth.js (SESSION_HOURS).

Backend connection

This is a placeholder field for when the Publish, Queue, and Channels pages connect to a real local server.

About this skeleton

Five pages, one shared style sheet, one login gate. No backend, no database — just the structure to build the real automation console into, one page at a time.
